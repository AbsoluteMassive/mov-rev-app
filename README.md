# Movie Review App

A movie app that lets users discover popular, upcoming and top-rated movies using the [TMDB](https://www.themoviedb.org/) API. It also allows users to create their own watchlist and keep track of movies they've already watched.

## GitHub Pages
For preview [Movie review app](https://absolutemassive.github.io/mov-rev-app/)

## Built with
HTML, CSS, JavaScript, TMDB API, LocalStorage, React, Vite.
